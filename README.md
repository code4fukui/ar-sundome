# ar-sundome

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

This repository demonstrates the use of anchors to place virtual objects in stable, real-world locations. It includes a 3D model of a sundome that can be displayed in AR or VR.

## Demo
https://code4fukui.github.io/ar-sundome/

## Features
- Displays a 3D sundome model in AR or VR
- Anchors the sundome to a stable real-world location

## Requirements
- WebXR-compatible web browser

## Usage
The project can be run by opening the `index.html` file in a WebXR-compatible web browser. It will automatically detect if AR or VR is available and provide the appropriate interface.

## Data
- Sundome 3D model: https://github.com/digitaltwin-echizen/vr-sundome/
- Other WebXR samples: https://github.com/immersive-web/webxr-samples/
