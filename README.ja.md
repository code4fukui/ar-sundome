# ar-sundome

このリポジトリは、アンカーを使用して仮想オブジェクトを現実世界の安定した場所に配置する方法を示しています。ARまたはVRで表示できるサンドームの3Dモデルが含まれています。

## デモ
https://code4fukui.github.io/ar-sundome/

## 機能
- 3DサンドームモデルをARまたはVRで表示
- サンドームを現実世界の安定した場所に固定（アンカー）

## 必要条件
- WebXR対応のウェブブラウザ

## 使い方
WebXR対応のウェブブラウザで `index.html` ファイルを開くことで実行できます。ARまたはVRが利用可能かを自動的に検出し、適切なインターフェースを提供します。

## データ
- サンドーム3Dモデル: https://github.com/digitaltwin-echizen/vr-sundome/
- その他のWebXRサンプル: https://github.com/immersive-web/webxr-samples/
